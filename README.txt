HEY BRO - Android app source
Option A (phone only): create a GitHub repo, upload ALL files from this zip (keep the .github folder),
open Actions > Build APK > Run workflow, then download "HeyBro-apk" from the finished run, unzip, install app-debug.apk
(allow "install unknown apps").
Option B (PC): open this folder in Android Studio > Build > Build APK(s).
